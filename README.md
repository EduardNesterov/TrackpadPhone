# TrackpadPhone

iPhone как трекпад для Mac. Локально по Wi-Fi, без облака.

Архитектура и обоснования решений — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Состояние: M0

M0 существует ради **одного числа** — сквозной задержки. Пока это не измерено на живом
телефоне через настоящий Wi-Fi, строить остальное бессмысленно: если задержка окажется
плохой, менять придётся транспорт, то есть фундамент.

Что уже есть и проверено:

| | |
|---|---|
| `TrackpadKit/` | кодек протокола, 17 тестов, `swift test` |
| `Spike/mac-receiver/` | UDP-приёмник → CGEvent. Курсор и тап. Выбрасывается после M1 |
| `Spike/fake-phone.py` | тестовый телефон: гоняет Mac-часть без iPhone |
| `Apps/TrackpadPhoneiOS/` | поверхность касаний, отправка кадров, замер RTT на экране |

Чего в M0 намеренно нет: обнаружения по Bonjour, шифрования, пейринга, скролла и жестов.
Каждое из них — только лишний способ провалить измерение.

## Запуск

### 1. Mac

```bash
cd Spike/mac-receiver && swift run mac-receiver
```

Приёмник печатает адрес, который надо ввести на телефоне.

**Нужно разрешение Accessibility**, иначе курсор не двинется. Для бинарника, запущенного из
терминала, macOS приписывает разрешение **терминалу**, а не самому бинарнику:

> System Settings → Privacy & Security → Accessibility → добавить Terminal (или iTerm),
> включить, полностью выйти из терминала (⌘Q) и запустить заново.

Приёмник сам скажет, если разрешения нет.

### 2. iPhone

Сборка и установка без Xcode:

```bash
xcodebuild -project TrackpadPhone.xcodeproj -scheme TrackpadPhoneiOS \
  -destination 'generic/platform=iOS' -allowProvisioningUpdates build
```

```bash
xcrun devicectl list devices
```

```bash
xcrun devicectl device install app --device <UDID> \
  ~/Library/Developer/Xcode/DerivedData/TrackpadPhone-*/Build/Products/Debug-iphoneos/TrackpadPhone.app
```

**Первый запуск потребует доверия на самом телефоне**, иначе система откажет с
`invalid code signature … profile has not been explicitly trusted`:

> Настройки → Основные → VPN и управление устройством → приложение разработчика → Доверять

Дальше — ввести адрес Mac, нажать Connect, водить пальцем.

Профиль бесплатного аккаунта живёт **7 дней** (текущий — до 13 августа 2026), потом
приложение надо переустановить той же командой.

#### Подводный камень: DEVELOPMENT_TEAM

Team ID — это поле **OU** в сертификате, а не значение в скобках после имени. Значение в
скобках относится к самому сертификату, и подстановка его в `DEVELOPMENT_TEAM` даёт сбивающую
с толку ошибку `No Account for Team`, которая выглядит как отсутствие аккаунта в Xcode:

```bash
security find-certificate -c "Apple Development" -p | openssl x509 -noout -subject
```

`/UID=…/CN=Apple Development: почта (ЭТО НЕ TEAM ID)/OU=ВОТ TEAM ID/O=…`

### Проверка Mac-части без телефона

```bash
python3 Spike/fake-phone.py 127.0.0.1
```

Синтезирует свайп, дубликат, устаревший кадр и тап. Пакеты собираются прямо по спецификации,
а не моим же Swift-кодеком, поэтому расхождение форматов — настоящая находка, а не общий баг.

### Тесты

```bash
cd TrackpadKit && swift test
```

## Что читать в выводе приёмника

```
  61 fps   gap p50  10.5 ms   p95  10.7 ms   lost 0   discarded 2
```

- `lost` — дыры в нумерации, то есть **реальные потери сети**. Вот за этим и следим.
- `discarded` — дубликаты и кадры не по порядку, отброшенные намеренно. Норма, не проблема.

Эти два числа специально разведены: смешанные, они превращают исправную работу дедупликации
в видимость сетевых потерь.

RTT показывает **телефон** — только у него оба штампа времени на одних часах, поэтому
синхронизация часов с Mac не нужна и не делается.

## Ориентир по задержке

Касание 8 мс + сеть 2–15 мс + обработка <1 мс + композитор 8–16 мс ≈ **20–40 мс**.
Ниже ~50 мс ощущается мгновенным, выше — курсор заметно тянется за пальцем.
